# Security policy

Analytics Dashboard is pre-alpha and **not production-ready**. Do not expose this development version to customer traffic or secrets.

## Reporting a vulnerability

Use GitHub's private **Report a vulnerability** feature under the Security tab if available, or contact the repository owner privately. Never publish exploit details or real customer data in a GitHub issue.

Include the affected commit, reproducible steps, prerequisites, impact, and a suggested mitigation if known.

## Supported versions

There are no supported releases yet. Fixes are developed on branches, tested and reviewed before merging.

See the [security boundaries document](docs/security.md) for implemented safeguards and remaining controls.

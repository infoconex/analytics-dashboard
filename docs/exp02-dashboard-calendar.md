# EXP-02 — Experimental dashboard calendar

Issue #137. Only experiment/dashboard-filtering. The original fictional commerce rows are month aggregates with unspecified year; marketing has no dates. Do not assign fake event timestamps or reinterpret those records. The header contains an opt-in, per-dashboard calendar evaluation with two independent fixed event fixtures (Sales OrderDate and Support OpenedAt) and an undated inventory fixture. It applies one UTC interval to mapped raw records before aggregation. It does not modify saved widgets; integrating the context into authored visualizations is EXP-04. No customer connections, APIs, production catalog, designer persistence or changes to existing sample filter URL/handoff behavior.

Approved presets: Last 1 day (24 elapsed hours), Last 1 week (7 elapsed days), Last 1 month, Last 3 months, Last 12 months (local calendar subtraction with month-end clamping), Today, Yesterday, This week, This month, This year, Last year, Custom date/time range and All time. Current periods end at the same Apply clock snapshot. Yesterday and Last year cover the complete preceding calendar period. The week starts on the selected weekday (Monday default). Zone is explicit (UTC default; a bounded list plus browser zone). All time is unrestricted. The custom end is exclusive. Invalid ranges do not alter the applied range. A custom ambiguous or nonexistent wall time is rejected, with instructions to use another time or UTC. For preset boundaries the earlier instant is chosen when repeated, and nonexistent boundaries fail explicitly. At an exact current-period boundary, a zero-length interval is rejected. Browser Intl timezone rules are used; custom input supports minutes and years 1970–9998.

The resolved range has start/end ISO UTC instants aligned to EXP-01 SharedDateRange; no backend endpoint is added. Fixtures are static (November 2025/2026); rolling selections outside that coverage can correctly yield no matching records, not invented zeros. A new Apply reevaluates relative time; reload resets this memory-only experiment (no persisted configuration yet). No live refresh or user-supplied expressions. Existing provider compilers and conformance remain gated; direct cross-provider execution of experimental contexts is EXP-06.

Verification: unit calendar and fixture tests, embedded browser keyboard, date entry, invalid DST, reset, width/forced-colors/axe and screenshot evidence, plus existing CI and CodeQL. Native zoom coverage in existing browser regression tests is not a claim of specific calendar native-zoom testing. Human usability and screen-reader review are not yet performed.
